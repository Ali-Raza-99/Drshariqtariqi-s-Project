# QUICK START - Guest User Data Access Fix

## The Problem (In 30 seconds)
- Guest users see: "Oil", "Bakhor", "Powder" (hardcoded)
- Console error: `permission-denied`
- Reason: Firestore rules block unauthenticated access

## The Solution (In 30 seconds)
Update Firestore Security Rules to allow public read access for products/courses

## Time to Fix
⏱️ **5-10 minutes total**

---

## STEP 1: Get the New Rules (Copy This)

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // Public read access
    match /products/{productId} {
      allow read: if true;
      allow create, update, delete: if request.auth != null && 
                                       get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin';
    }
    
    match /courses/{courseId} {
      allow read: if true;
      allow create, update, delete: if request.auth != null && 
                                       get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin';
    }
    
    // Protected collections
    match /users/{userId} {
      allow read: if request.auth != null && request.auth.uid == userId;
      allow create: if request.auth != null && request.auth.uid == userId;
      allow update: if request.auth != null && request.auth.uid == userId;
    }
    
    match /cart/{cartItem} {
      allow read, write: if request.auth != null;
    }
    
    match /orders/{orderId} {
      allow read, write: if request.auth != null;
    }
    
    match /Appointment/{appointmentId} {
      allow read, write: if request.auth != null;
    }
    
    match /mureeds/{mureedId} {
      allow read, write: if request.auth != null;
    }
    
    match /qurbaniAnimals/{animalId} {
      allow read, write: if request.auth != null;
    }
    
    match /qurbaniBanks/{bankId} {
      allow read, write: if request.auth != null;
    }
  }
}
```

## STEP 2: Go to Firebase Console
1. https://console.firebase.google.com
2. Select your project
3. **Firestore Database** (left sidebar)
4. **Rules** tab (top)

## STEP 3: Replace Rules
1. Select all (Ctrl+A)
2. Delete
3. Paste rules from STEP 1
4. Click **Publish**
5. Wait for green checkmark ✅

## STEP 4: Test It Works
1. Open incognito browser
2. Go to localhost:5174/products
3. Open DevTools (F12)
4. Console should show:
   ```
   ✅ [Products] Fetch successful
   ```
5. Products should display (not just Oil/Bakhor/Powder)

## If It Still Doesn't Work

### ❌ Still seeing "permission-denied"?
- Hard refresh: Ctrl+Shift+R
- Clear cache: Ctrl+Shift+Delete
- Wait 2 minutes for rules to deploy
- Check Firestore collections exist

### ❌ Products not updating?
- Firestore collections might be empty
- Check: Firestore Console → Collections → products (should have items)

### ❌ Errors in console?
- Check exact error code
- Compare your rules to provided rules above
- Verify no typos
